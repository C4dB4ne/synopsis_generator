= GET /health/dependencies - Проверить Ollama и PostgreSQL

[.text-right]
{document-name}.adoc

toc::[]

== Описание
Метод `GET /health/dependencies` проверяет прямые инфраструктурные зависимости FastAPI-приложения:

- Ollama;
- PostgreSQL.

Проверка выполняется последовательно. При ошибке любой зависимости API возвращает `HTTP 503 Service Unavailable`.

**ПРИМЕЧАНИЕ**: MCP Server этим endpoint не проверяется. MCP подключается во время выполнения workflow через `get_mcp_tools_safely`.

**ПРИМЕЧАНИЕ**: Проверка Ollama вызывает `/api/version` и подтверждает доступность сервиса, но не проверяет наличие модели из `LLM_MODEL`.

[[A1]]
=== A1 Проверка Ollama
Выполняется HTTP-запрос:

[source]
----
GET {OLLAMA_BASE_URL}/api/version
timeout = 5s
----

При ошибке возвращается `HTTP 503` с `detail = "Ollama unavailable: ..."`.

[[A2]]
=== A2 Проверка PostgreSQL
Выполняется подключение по `DATABASE_URL` и SQL:

[source,sql]
----
SELECT current_database(), current_user
----

При ошибке возвращается `HTTP 503` с `detail = "PostgreSQL unavailable: ..."`.
