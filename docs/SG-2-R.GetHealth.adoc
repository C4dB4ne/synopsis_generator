= GET /health - Проверить доступность API

[.text-right]
{document-name}.adoc

toc::[]

== Описание
Метод `GET /health` проверяет, что FastAPI-приложение запущено и может обработать HTTP-запрос.

Метод не выполняет проверку Ollama, PostgreSQL или MCP Server.

Для проверки прямых зависимостей API используется link:SG-2-R.GetHealthDependencies.adoc[].
