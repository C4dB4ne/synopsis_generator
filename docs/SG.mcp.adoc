== Описание
Synopsis MCP Server реализован на `FastMCP`, запускается отдельным контейнером и слушает HTTP на `0.0.0.0:8001`.

На стороне FastAPI используется `langchain-mcp-adapters` / `MultiServerMCPClient`.

Текущая конфигурация содержит один MCP server entry:

[source]
----
synopsis -> MCP_SERVER_URL
----

MCP tools загружаются во время выполнения workflow. `get_mcp_tools_safely()` ограничивает подключение `MCP_CONNECT_TIMEOUT_SECONDS`; при timeout или ошибке возвращается пустой список.

== Архитектура tool
Tool functions используют dependency injection через `Depends(get_*_service)`.

Основная цепочка:

[source]
----
LangGraph Node -> MCP Client -> FastMCP Tool -> Service -> PostgreSQL / HTTP
----

Tool не содержит SQL-логику предметной операции; работа с PostgreSQL и внешними HTTP endpoints вынесена в service layer.
