== Описание домена
Предметная модель Synopsis Generator разделяет литературный проект, конкретную generation и версию долговременной памяти.

Основной агрегат — `StoryProject`.

- `StoryProject` хранит постоянные параметры произведения и актуальный StoryMemory snapshot.
- `SynopsisGeneration` хранит результат одного завершенного workflow.
- `StoryMemoryVersion` хранит immutable snapshot памяти после конкретного этапа развития истории.

LangGraph `thread_id` является техническим идентификатором workflow и не является primary key предметной сущности. Checkpoint-таблицы создаются и обслуживаются библиотекой `AsyncPostgresSaver`.

story_projects ||--o{ synopsis_generations : story_id\nON DELETE SET NULL

== StoryMemory
Поле `story_projects.memory` и `story_memory_versions.memory` содержит JSONB в формате `StoryMemory`.

[width="100%", cols="1, 5, 3, 1, 6"]
|===
|# |Parameter |Type |Required |Description
|{counter:M1} |`summary` |`string` |+ |Краткое каноническое состояние истории
|{counter:M1} |`characters` |`array of object` |+ |Персонажи
|{counter:M1} |`characters.name` |`string` |+ |Имя персонажа
|{counter:M1} |`characters.role` |`string` |+ |Роль
|{counter:M1} |`characters.current_state` |`string` |+ |Текущее состояние
|{counter:M1} |`characters.goals` |`array of string` |+ |Цели
|{counter:M1} |`world_facts` |`array of string` |+ |Факты мира
|{counter:M1} |`locations` |`array of string` |+ |Локации
|{counter:M1} |`unresolved_threads` |`array of string` |+ |Незавершенные сюжетные линии
|{counter:M1} |`latest_events` |`array of string` |+ |Последние события
|{counter:M1} |`style_rules` |`array of string` |+ |Правила стилистической последовательности
|===

== LangGraph checkpoint tables
`AsyncPostgresSaver.setup()` создает собственные технические таблицы checkpoint.

Эти таблицы находятся в той же PostgreSQL БД, но не относятся к предметной metadata Synopsis Generator и не управляются Alembic-миграциями проекта.

Их назначение — сохранение state одного `thread_id` и возобновление Human-in-the-Loop workflow через `Command(resume=...)`.
