= POST /api/v1/synopsis/resume - Продолжить приостановленный workflow

[.text-right]
{document-name}.adoc

toc::[]

== Описание
Метод `POST /api/v1/synopsis/resume` продолжает LangGraph workflow, ранее приостановленный через `interrupt()` в `wait_for_clarification`.

Клиент передает `thread_id` из ответа `POST /api/v1/synopsis` и свободный ответ пользователя на уточняющий вопрос.

API вызывает `Command(resume=message)` с тем же `configurable.thread_id`. PostgreSQL checkpointer восстанавливает состояние workflow, после чего `wait_for_clarification` выполняется заново и получает resume value.

**ПРИМЕЧАНИЕ**: Этот endpoint не предназначен для создания следующей части уже завершенной истории. Для продолжения истории между независимыми workflow используется новый link:SG-1-C.PostCreateSynopsis.adoc[] с существующим `story_id`.

== Доступные роли
Аутентификация и пользовательские роли в текущей версии не реализованы.

=== R2 Response
Формат ответа совпадает с link:SG-1-C.PostCreateSynopsis.adoc#R2[].

[[A1]]
=== A1 Восстановление workflow
API вызывает:

[source]
----
Command(resume=payload.message)
----

и передает прежний `thread_id` в:

[source]
----
configurable.thread_id
----

Checkpointer восстанавливает сохраненное состояние thread.

[[A2]]
=== A2 Получение ответа в wait_for_clarification
По правилам LangGraph прерванный узел запускается заново с начала.

Повторный вызов `interrupt()` возвращает переданное resume value вместо новой остановки. Узел:

- записывает значение в `latest_user_message`;
- увеличивает `clarification_count` на `1`;
- очищает `clarification_message`;
- устанавливает `status = clarification_received`.

[[A3]]
=== A3 Повторный анализ требований
После `wait_for_clarification` graph edge возвращает workflow в `collect_requirements`.

См. link:SG-1-C.PostCreateSynopsis.adoc#A3[].

Если требований все еще недостаточно и лимит не достигнут, workflow снова приостанавливается через `interrupt()`.

Если `clarification_count >= max_clarifications`, выполняется `clarification_limit_reached`.

[[A4]]
=== A4 Продолжение генерации после полного ТЗ
Если требования полны, workflow продолжает алгоритм с создания/проверки Story Project.
